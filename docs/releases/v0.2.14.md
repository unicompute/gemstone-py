# gemstone-py 0.2.14

This patch release publishes the follow-up Codegen examples, documentation, and
VS Code workbench screenshots after the `0.3.0` Codegen Explorer feature
release.

## Highlights

- Added an offline Codegen preview example that generates wrappers into a
  temporary directory and prints the exact check/generate commands.
- Added a live generated-wrapper probe example for checking generated calls
  against a reachable GemStone stone.
- Added a reusable Codegen Workbench mapping example for selecting classes,
  selectors, and output targets.
- Expanded the README, examples guide, Codegen guide, Medium article draft,
  typed Codegen demo docs, and workbench README with concrete Codegen commands
  and selector examples.
- Published Workbench `0.3.1` with refreshed Codegen screenshots for the
  Command Palette, sidebar actions, and Codegen Explorer workflow.

## Install

```bash
python -m pip install gemstone-py==0.2.14
```

For the optional native PyO3 backend:

```bash
python -m pip install "gemstone-py[fast]==0.2.14"
python -c "from gemstone_py import _gci; print(_gci.IMPLEMENTATION)"
```

For the VS Code workbench:

```bash
code --install-extension unicompute.gemstone-py-workbench
```

Local VSIX:

```bash
code --install-extension gemstone-py-workbench-0.3.1.vsix --force
```
