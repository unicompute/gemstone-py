# gemstone-py 0.2.10

This release focuses on making the FastAPI example installable and runnable for
new users, while keeping the optional native GCI backend easy to verify from
PyPI and TestPyPI.

## Highlights

- Added `fastapi` and `examples` extras for explicit FastAPI/uvicorn installs.
- Added `gemstone-fastapi-example`, `gemstone-examples fastapi`, and
  `python -m examples.fastapi.run` runners with dependency checks.
- Added a FastAPI index route at `/`, startup verification instructions, and a
  clean 503 response when GemStone credentials are missing.
- Kept the default GCI backend pure ctypes, with native acceleration available
  through `gemstone-py[fast]`.
- Verified `gemstone-py-native 0.1.2` wheels on PyPI and TestPyPI.

## Install

```bash
python -m pip install gemstone-py==0.2.10
```

For the optional native PyO3 backend:

```bash
python -m pip install "gemstone-py[fast]==0.2.10"
python -c "from gemstone_py import _gci; print(_gci.IMPLEMENTATION)"
```

For FastAPI examples:

```bash
python -m pip install "gemstone-py[fastapi]==0.2.10"
gemstone-fastapi-example --reload
```

For a source checkout:

```bash
python -m pip install -e ".[examples]"
python -m examples.fastapi.run --reload
```
