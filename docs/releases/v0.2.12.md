# gemstone-py 0.2.12

This patch release publishes the VS Code workbench Codegen command surface so
the typed-wrapper workflow is available from the sidebar and Command Palette.

## Highlights

- Added `GemStone: Run Codegen Check` for validating committed generated
  wrappers with `gemstone_py.codegen --check`.
- Added `GemStone: Generate Codegen Wrappers` for regenerating the demo wrappers
  with stale-file cleanup.
- Added `GemStone: Run Codegen FastAPI Demo` for launching
  `examples.typed_access.codegen_demo.run --reload`.
- Added `GemStone: Open Codegen Docs` in the Command Palette, Examples view,
  and Docs view.
- Added smoke coverage for the Codegen command wiring.

## Install

```bash
python -m pip install gemstone-py==0.2.12
```

For the optional native PyO3 backend:

```bash
python -m pip install "gemstone-py[fast]==0.2.12"
python -c "from gemstone_py import _gci; print(_gci.IMPLEMENTATION)"
```

For the VS Code workbench:

```bash
code --install-extension unicompute.gemstone-py-workbench
```
