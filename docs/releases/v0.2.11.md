# gemstone-py 0.2.11

This release publishes the plan3 implementation pass: richer framework
adapters, production session-provider internals, typed Codegen workflows,
observability, migrations, inspection tools, release verification, and updated
examples.

## Highlights

- Added `gemstone_py.session_providers`, `gemstone_py.web_core`, Flask/Django
  adapters, FastAPI pool dependencies, and Litestar dependency helpers.
- Added `gemstone-codegen`, Protocol-to-`TypedOop` wrapper generation,
  generated `.pyi` stubs, stale-wrapper cleanup, and a generated-wrapper
  FastAPI demo.
- Added `gemstone-migrations` planning, dry-run, upgrade/downgrade, status,
  class-diff, manifest drift, and GemStone-side advisory locking.
- Added `gemstone_py.observability` with no-op, OpenTelemetry, Prometheus,
  session, pool, and query iterator instrumentation.
- Added `GemStoneSession.inspect(...)`, class/object dump helpers, and the
  `gemstone-inspect` CLI.
- Added chunked sync/async query iterators and benchmark coverage for materialized
  versus streamed result reads.
- Added `gemstone-examples list`, `gemstone-examples plan3-map`,
  `gemstone-examples litestar`, `gemstone-litestar-example`, `examples/cookbook/`,
  and `examples/litestar/`.
- Added `gemstone-publish-verify` for end-to-end PyPI/TestPyPI JSON, simple
  index, and install verification.
- Updated the VS Code workbench to run the new example catalog, quickstart,
  Litestar, and Plan3 feature map commands.

## Install

```bash
python -m pip install gemstone-py==0.2.11
```

For the optional native PyO3 backend:

```bash
python -m pip install "gemstone-py[fast]==0.2.11"
python -c "from gemstone_py import _gci; print(_gci.IMPLEMENTATION)"
```

For web examples:

```bash
python -m pip install "gemstone-py[fastapi]==0.2.11"
gemstone-fastapi-example --reload

python -m pip install "gemstone-py[litestar]==0.2.11"
gemstone-litestar-example --reload
```

For a source checkout:

```bash
python -m pip install -e ".[examples]"
gemstone-examples list
gemstone-examples plan3-map
python -m examples.quickstart
python -m examples.litestar.run --reload
```
