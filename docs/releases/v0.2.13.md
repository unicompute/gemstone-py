# gemstone-py 0.2.13

This patch release pairs the Python package docs/examples updates with
`gemstone-py Workbench` `0.3.0`, the first visual Codegen Explorer release.

## Highlights

- Added `GemStone: Open Codegen Explorer` in the VS Code workbench `0.3.0`
  release.
- The Codegen Explorer connects to the configured
  `python-gemstone-database-explorer`, browses live
  dictionaries/classes/protocols/methods/source, selects wrapper targets,
  previews generated wrappers in a temporary directory, diffs generated output
  against the repository, saves `codegen-workbench.json`, and runs live target
  probes.
- Documented the visual Codegen workflow in the README, examples guide,
  Codegen guide, Medium article draft, and workbench README.
- Clarified source-checkout `examples.*` commands versus installed package
  console scripts.
- Made the Litestar example index route identify its framework adapter and
  dependency-injection path.

## Install

```bash
python -m pip install gemstone-py==0.2.13
```

For the optional native PyO3 backend:

```bash
python -m pip install "gemstone-py[fast]==0.2.13"
python -c "from gemstone_py import _gci; print(_gci.IMPLEMENTATION)"
```

For the VS Code workbench:

```bash
code --install-extension unicompute.gemstone-py-workbench
```

Local VSIX:

```bash
code --install-extension gemstone-py-workbench-0.3.0.vsix --force
```
